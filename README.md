## Overview
**CosmoAnisotropy** is a professional-grade Python analytical toolkit designed to interrogate large-scale structure and test the foundational assumptions of modern cosmology ($\Lambda\text{CDM}$). 

Built specifically for processing coordinate geometry, conducting automated hemisphere splits, and running redshift tomography on standardized cosmological datasets (such as Pantheon+ Type Ia supernovae), this tool provides researchers with rigorous diagnostic pipelines to evaluate directional anisotropies and frame-dependent bulk flows.

---

## Key Features
* **Directional Residual Mapping:** Projects supernova data across 360-degree celestial coordinates to isolate directional anomalies.
* **Automated Hemisphere Splits:** Tests data symmetry across custom apex vectors to interrogate the Cosmological Principle.
* **Built-In Identity & Watermarking:** Features hardcoded rendering security to ensure authorship and enterprise metadata remain permanently tied to all generated visual assets.
